# Task 5: Capstone Integration & Portfolio Finalization

## Project Overview
This task brings together all four previous tasks completed during the AICTE ApexPlanet Data Analytics Internship.

The objective is to organize the project deliverables, summarize key findings, and present the complete work professionally through GitHub and a portfolio website.

## Completed Tasks

### Task 1: Data Immersion & Data Wrangling
- Explored the sales dataset.
- Checked missing values and duplicate records.
- Performed data cleaning and preprocessing.

### Task 2: Exploratory Data Analysis (EDA)
- Analyzed sales and customer data.
- Identified sales trends and patterns.
- Studied product, category, and city-wise performance.

### Task 3: Analysis & Dashboard
- Created interactive Power BI dashboards.
- Analyzed sales performance.
- Performed RFM customer segmentation.

### Task 4: Data Storytelling & Statistical Validation
- Prepared business insights and recommendations.
- Performed hypothesis testing using Python.
- Interpreted statistical results.

## Final Project Highlights

- Top Performing City: Patna
