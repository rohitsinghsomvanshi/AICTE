## Project Highlights

### Sales Analysis

The analysis explores sales performance across products, categories, cities, and time. The Power BI sales dashboard includes measures such as total sales, units sold, unique customers, and average order value, along with interactive visual analysis.

### Customer Segmentation with RFM

Customers were analyzed using three RFM dimensions:

- **Recency:** How recently a customer made a purchase.
- **Frequency:** How often a customer placed an order.
- **Monetary:** How much a customer spent.

The project groups customers into five segments: High Value Recent, At Risk High Value, Regular Customers, Recent Low Value, and Inactive Low Value. The repository includes the customer-level segmentation output, segment summary, and Power BI dashboard.

**Interpretation note:** The available dataset contains many customers with only one recorded order. Repeat-purchase patterns should therefore be interpreted with this limitation in mind.
